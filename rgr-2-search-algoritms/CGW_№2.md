## 1.1 Основные понятия оценки сложности алгоритмов

**Сложность алгоритма** - это функция, описывающая зависимость потреблений ресурсов (Времени выполнения или объёма памяти) от размера входных данных.

Выделяют два основных вида сложности:

1. **Временная сложность** (time Complexity) - Показывает как увеличивается время выполнения алгоритма при росте входных даныых.
2. **Пространственная сложность** (Space Complexity) - Показывает какой объём оперативной памяти требуется алгоритму для работы по мере роста объёма входных данных.

Для описания сложности алгоритма в программировании используются асимптотические нотации, которые формирую следующие классы сложности.

* O(1) - Константная
* O(n) - Линейная
* O(n<sup>2</sup>) - Квадратическая
* O(log<sub>n</sub>) - Логарифмическая
* O(n log<sub>n</sub>) - Линейно-логарифмическая

## 1.2 Алгоритмы поиска и их реализация на Python

### 1.2.1 Линейный поиск (Linear search)

Алгортм последовательно проверяет элемент списка, пока не будет найдено искомое значение или пока не закончится массив данных. 

```py
def linear_search(list, target):
    """ Линейный поиск: возвращает индекс искомого элемента, 
    а если не будет найден то возвращает -1"""
    for i, value in enumerate(list):
        if value == target:
            return i
    return -1

# Реализация
import random

massive = [random.randint(1,100)for _ in range(100000)]
linear_search(massive, 50)
```

Временная сложность линейного алгоритма оценивается как:
* В худшем случае O(n) - если искомый элемент находится в конце или отсутсвует вовсе.
* В среднем случае O(n)
* В лучшем случае O(1)

Пространственная сложность оценивается всегда O(1), т.к дополнительная память не используется а сам массив оценивается сразу же.

### 1.2.2 Бинарный поиск (binary search)

Данный алгоритм работает только на отсортированных массивах.

Отсортированный массив делится напополам, далее сравниваетмя средний элемент с исходным и отбрасывается та половина, где этого элемента точно быть не может.

После этого механика поиска повторяется аналогично на оставшейся половине.

```py
def binary_search(arr, target):
    """ Бинарный поиск: возвращает индекс искомого элемента, 
    а если не будет найден то возвращает -1"""
    left, right = 0, (len(arr)-1)
    while left <= right:
        middle = (left+right) // 2
        if arr[middle] == target:
            return middle
        elif arr[middle] < target:
            left = middle+1
        else:
            right = middle-1
            
    return -1

# Реализация
import random
massive = [random.randint(1,100)for _ in range(1000)].sort
binary_search(massive, 50)
```
Временная сложность бинарного алгоритма оценивается как:
* В худшем случае O(log<sub>n</sub>) - на каждой итерации размер диапазона уменьшается примерно вдвое.
* В лучшем случае O(1) - искомый элемент находится в середине массива

Пространственная сложность оценивается как:
* В итеративном варианте - O(n) 
* В рекурсивном варианте - O(log<sub>n</sub>)
