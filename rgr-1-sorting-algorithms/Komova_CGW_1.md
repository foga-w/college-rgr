# 1. Теоретическая часть.

## 1.1 Основные понятия оценки сложности алгоритмов

**Сложность алгоритма** - это функция, описывающая зависимость потреблений ресурсов (Времени выполнения или объёма памяти) от размера входных данных.

Выделяют два основных вида сложности:

1. **Временная сложность** (time Complexity) - Показывает как увеличивается время выполнения алгоритма при росте входных даныых.
2. **Пространственная сложность** (Space Complexity) - Показывает какой объём оперативной памяти требуется алгоритму для работы по мере роста объёма входных данных.

Для описания сложности алгоритма в программировании используются асимптотические нотации, которые формирую следующие классы сложности.

* O(1) - Константная
* O(n) - Линейная
* O(n<sup>2</sup>) - Квадратическая
* O(log<sub>n</sub>) - Логарифмическая
* O(n log<sub>n</sub>) - Линейно-логарифмическая

## 1.2 Алгоритмы сортировки и их реализация на Python

Для исследования выбраны четыре классических алгоритмы сортировки данных: два - с квадратичной сложностью (пузырьковая сортировка и сортировка выбором), и два с линейно-логарифмической сложностью (быстрая сортировка и сортировка слиянием)

### 1.2.1 Пузырьковая сортировка. (Bubble Sort)

Алгоритмы последовательно сравниваюи сосендние элементы массива и меняет их местами. если они стоят в неправильном порядке. Таким образом тяжёлые "элементы" постеменно перемещаются в конец массива.

```py
def Bubble_Sort(arr):
    # 1. Замер длинны массива
    n = len(arr)
    # 2. Проход по всем элементам массива.
    for i in range(n):
        flag = False # Флаг: Были ли обмены на текущем проходе 
        # Последние i элементов были отсортированы, их трогать не нужно.
        for j in range(0, n-i-1):
            if arr[j]>arr[j+1]:
                # Меняем соседние элементы местами
                arr[j], arr[j+1] = arr[j+1], arr[j]
                flag = True
        # Если обменов не было, то массива отсортирован 
        if not flag:
            break

    return arr
```

Алгоритм прост в своей механике благодарая флагу `flag`в лучшем случае (Уже остортированный массив) работает по нотации Линейного типа O(n). В худшем и средней случае работает по нотации Квадратической сложности (n<sup>2</sup>)<br>
Дополнительная память не требуется, сортировка выполняется "на месте", и таким образом пространственная сложность рабоатет по константной нотации O(1).

### 1.2.2 Сортировка выбором (Selection Sort)

Алгоритм делит массив на отсортированную и неотсортированную части. На каждом шаге в неотсортированной части ищется минимальный элемент и перемещается в конец отсортированного.

```py
def Selection_Sort(arr):
    # 1. Замер длинны массива
    n = len(arr)
     # 2. Проход по всем элементам массива.
    for i in range(n):
        min_index = i # Предполагаем, что текущий элемент минимальный.
        #Ищем реальный минимум в оставшейся части массива 
        for rel_min in range(0, i+1, n):
            if arr[rel_min]<arr[min_index]:
                min_index = rel_min
        # Меняйем местами найденный минимум и текущий элемент 
        arr[i], arr[min_index] = arr[min_index], arr[i]

    return arr
```

Алгорим всегда работает по нотации Квадратической сложности (n<sup>2</sup>) независимо от начального  порядка элементов. Память потребляется только для хранения нескольких индексов, потому пространственная сложность - O(n) не меняется

### 1.2.3 Быстрая сортировка (Quick Sort)

Алгоритм, основанный на принципе "разделяй и властвуй": Выбираетмя опорный элемент (pivot), массив делится на элементы больше, равные и меньше опорного, после чего части сортируются рекурсивно.

```py
def Quick_Sort(arr):
    # 1. Замер длинны массива
    n = len(arr)
    # Базовый случай рекурсии: Массив, состоящий из 0 или 1 элемента является отсортированным.
    if n<=1:
        return arr
    # 2. Сравнение элементов
    pivot = arr[n//2] # выбиваем серединный элемент массива как опорник.
    left = [x for x in arr if x < pivot]    # Элементы меньше опорного
    right = [x for x in arr if x > pivot]       # Элементы больше опорного
    middle = [x for x in arr if x == pivot]     #Элементы равные опорному 

    # Рекурсивно сортируем левую и правую части и объединяем 
    return Quick_Sort(left) + middle + Quick_Sort(right)
```

Алгоритм работы с созданием новых списков - списки left, middle и right. Что увеличивает потребление памяти до O(n). Временная сложность оценивается по O(n log<sub>n</sub>) по нотации средней сложности. и по O(n<sup>2</sup>) в худших случаях.

### 1.2.4 Сортировка слиянием (Merge Sort)

Массив рекурсивно делится пополам до массивов. состаящих из 1 элемента. После чего происходит слияние отсортированных частей в единый массив.

```py
def Merge_Sort(arr):
    # 1. Определяем длинну массива
    n = len(arr)
    if n<=1:
        return arr
    # 2. Определить середину массива для последующего его разделения.
    mid = n // 2
    # 3. Рекурсивно делим массив на две половины и сортируем.
    left_half = Merge_Sort(arr[:mid])
    right_half = Merge_Sort(arr[mid:])
    return merge(left_half, right_half)

def merge(left, right):
    result = []
    i = j = 0
    # Слияние двух отсортированных половин
    while i<len(left) and j<len(right):
        if left[i]<right[j]:
            result.append(left[i])
            i+=1
        else:
            result.append(right[j])
            j+=1
    # Добавляем оставшеся элементы
    result.extend(left[i:])
    result.extend(right[j:])
    return result
```

Этот алгоритм гарантирует временную сложность линейно-логарифмического типа O(n log<sub>n</sub>) для любого набора данных. Однако требует дополнительной памяти для промежуточных массивов, что по нотации определяет его пространственную сложность как O(n).

import random
import timeit

from sorts import Selection_Sort, Bubble_Sort, Quick_Sort, Merge_Sort

def measure_time(arr, sort_function, number):
    """Измеерние врмеени выполнения с помощью библиотеки timeit
    
    Параметры функции:
    sort_function - функция сортировки 
    arr - массиы данных
    number - количество повторений (для усреднения результата)

    Возвращает среднее время выполнения алгоритма в секундах.
    """
    def wrapper():
        """Функция, которая позволяет создавать копию массива перед его сортировкой
        для того, чтобы каждый запуск начинался с исходных значений.
        """
        arr_copy = arr.copy()
        sort_function(arr_copy)

    # Запускаем измерение 
    total_time = timeit.timeit(wrapper, number=number)
    # Возвращаем среднее время 
    return total_time / number

if __name__ == "__main__":
